# Bundled grammars and differential coverage

The package includes convenience helpers and grammar files for MATLAB and Markdown. The differential suite also checks tokenization against the vscode-textmate 9.3.2 oracle for these grammars:

| Grammar | Coverage |
|---------|----------|
| MATLAB | Bundled grammar and source corpus |
| Markdown | Bundled grammar and source corpus |
| Python | Differential corpus |
| TypeScript | Differential corpus |

The Registry API can load other TextMate grammars supplied by an application; this table describes bundled assets and oracle coverage, not an exhaustive compatibility list.
