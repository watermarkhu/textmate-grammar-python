textmate_grammar.engine.rules¶

Port of the Rule classes, RuleRegistry and the rule factory from vscode-textmate’s src/rule.ts (version 9.3.2, the pinned reference clone).

Ported from rule.ts: endRuleId/whileRuleId (rule.ts:17-20), the Rule base class (rule.ts:43-89), CaptureRule (rule.ts:96-120), MatchRule (rule.ts:122-164), IncludeOnlyRule (rule.ts:166-207), BeginEndRule (rule.ts:209-288), BeginWhileRule (rule.ts:290-379) and the RuleFactory (rule.ts:381-573) — i.e. createCaptureRule, getCompiledRuleId, _compileCaptures and _compilePatterns. The registry lives in Grammar upstream: registerRule/getRule are grammar.ts:245-254; the class RuleRegistry here extracts exactly that behaviour.

parse_include ports parseInclude and IncludeReferenceKind from src/grammar/grammarDependencies.ts (grammarDependencies.ts:247-295) — the minimal piece the rule factory needs for include resolution. init_grammar ports initGrammar (grammar.ts:410-421), which installs the $self/$base repository hooks.

Semantics are 1:1 with the reference; naming is pythonic where it can be (upstream member names are kept when the python port is simply “same words”), and every non-obvious piece carries a comment referencing the ported lines of rule.ts / grammar.ts / grammarDependencies.ts.
