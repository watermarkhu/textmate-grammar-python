textmate_grammar.engine.registry¶

Grammar registration and dependency loading from vscode-textmate v9.3.2.

The upstream Registry and SyncRegistry create the concrete Grammar class. That class is not available until task 3b, so the one deliberate seam here is an injectable grammar_factory(location, raw_grammar). Its default raises NotImplementedError; the later tokenizer task supplies the real constructor.

Upstream exposes asynchronous methods because its loader returns promises. This port intentionally uses synchronous callables returning raw grammar mappings (or None); dependency traversal, load caching, registration, and construction otherwise retain the upstream behavior. onig_lib is carried in the options for the eventual Grammar wiring, but is not consumed by this seam yet.
